Add music

四種方法，把歌放進來

用 iPhone、Mac 或 Windows 都可以。同名的 .lrc 歌詞檔會自動配對成歌詞。

不用裝軟體、不用接線

用瀏覽器把歌拖進手機

  1. 電腦和手機連到同一個 Wi-Fi
    家裡的 Wi-Fi 就可以。
  2. 點 App 首頁右上角的 Wi-Fi 圖示
    手機會顯示一個網址。第一次使用時請允許「區域網路」權限。
  3. 在電腦瀏覽器輸入那個網址
    Chrome、Edge、Safari 都可以。
  4. 把歌曲資料夾拖進網頁
    一個資料夾就是一張專輯，傳完回手機按「完成」→「匯入」。
歌已經在 iPhone、iCloud 雲碟或隨身碟裡

從「檔案」直接選

  1. 建立或打開一張專輯
    首頁右上角「＋」可以建立新專輯。
  2. 右上角「⋯」→「加入歌曲」
    可以從 iCloud 雲碟、Google 雲端硬碟、OneDrive 或 USB 隨身碟選取。
  3. 一次選取多首歌（和 .lrc 歌詞）
    依檔名自動排好順序。
用 USB 線連接

Finder 拖曳整個資料夾

  1. iPhone 接上 Mac，在 Finder 側邊欄點 iPhone
    第一次連接請在手機上按「信任」。
  2. 切到「檔案」分頁
    找到 MusicBox。
  3. 把歌曲資料夾拖到 MusicBox 上
    打開 App，左上角收件匣會出現數字，點進去按「匯入」。
Windows 10／11，用 USB 線連接

「Apple 裝置」App 拖曳

  1. 從 Microsoft Store 安裝「Apple 裝置」
    舊版 Windows 可以使用 iTunes。
  2. 接上 iPhone → 選「檔案」→ 找到 MusicBox
    第一次連接請在手機上按「信任」。
  3. 把歌曲資料夾拖進 MusicBox
    回到 App 點左上角收件匣，按「匯入」即可。

FAQ

常見問題

支援哪些音樂格式？

mp3、m4a、aac、wav、aiff、flac、caf。歌詞支援 .lrc（有時間軸、會跟著捲動）與 .txt（純文字）。

為什麼我的歌詞不會跟著音樂捲動？

純文字歌詞沒有時間資訊，所以只能整頁顯示。打開歌詞編輯器按「點按對時」，邊聽邊點一下，就能變成會捲動的歌詞。

對時點錯了怎麼辦？

不用重來！在對時畫面點錯的那一句，音樂會自動跳回前一句，從那裡重新點就好；也可以往右滑某一句，用 ±0.1 秒微調。

Wi-Fi 傳歌安全嗎？

只有在手機上打開「Wi-Fi 傳歌」畫面時才會接收檔案，關掉就停止。網址裡有一組每次都不同的存取碼，同一個 Wi-Fi 的其他人沒有存取碼就無法上傳；而且只接受音樂與歌詞檔。

我的音樂會上傳到雲端嗎？

不會。所有音樂與歌詞都只存在你的手機裡，App 不需要註冊帳號，也不會蒐集任何個人資料。

對方沒有安裝 App，可以分享給他嗎？

可以。長按歌曲選「分享音樂檔」，對方會收到一般的 mp3。若對方也有安裝 Share MusicBox，選「分享給 MusicBox 使用者」可以連歌詞、曲序和封面一起送過去。

可以放哪些音樂？

請放入你擁有或有權使用的音樂，例如自己購買的 CD 轉檔或自行錄製的音檔。分享給他人前，也請確認符合音樂的授權範圍。
