Add music

四種方法，把歌放進來

用 iPhone、Mac 或 Windows 都可以；放進來之後，就能離線聽、也能分享給家人。

不用裝軟體、不用接線

用瀏覽器把歌拖進手機

  1. 電腦和手機連到同一個 Wi-Fi
    家裡的 Wi-Fi 就可以。
  2. 點 App 首頁右上角的 Wi-Fi 圖示
    手機會顯示一個網址。第一次使用時請允許「區域網路」權限。
  3. 在電腦瀏覽器輸入那個網址
    Chrome、Edge、Safari 都可以。
  4. 把歌曲資料夾拖進網頁
    一個資料夾就是一張專輯，傳完回手機按「完成」→「匯入」。
歌已經在 iPhone、iCloud 雲碟或隨身碟裡

從「檔案」直接選

  1. 建立或打開一張專輯
    首頁右上角「＋」可以建立新專輯。
  2. 右上角「⋯」→「加入歌曲」
    可以從 iCloud 雲碟、Google 雲端硬碟、OneDrive 或 USB 隨身碟選取。
  3. 一次選取多首歌
    依檔名自動排好順序。
用 USB 線連接

Finder 拖曳整個資料夾

  1. iPhone 接上 Mac，在 Finder 側邊欄點 iPhone
    第一次連接請在手機上按「信任」。
  2. 切到「檔案」分頁
    找到 MusicBox。
  3. 把歌曲資料夾拖到 MusicBox 上
    打開 App，左上角收件匣會出現數字，點進去按「匯入」。
Windows 10／11，用 USB 線連接

「Apple 裝置」App 拖曳

  1. 從 Microsoft Store 安裝「Apple 裝置」
    舊版 Windows 可以使用 iTunes。
  2. 接上 iPhone → 選「檔案」→ 找到 MusicBox
    第一次連接請在手機上按「信任」。
  3. 把歌曲資料夾拖進 MusicBox
    回到 App 點左上角收件匣，按「匯入」即可。

FAQ

常見問題

沒有網路真的能聽嗎？

可以。音樂檔案存在你的手機裡，播放時完全不需要連線；開飛航模式也能聽。只有「Wi-Fi 傳歌」需要電腦和手機在同一個 Wi-Fi 下。

可以放哪些音樂、分享給誰？

Share MusicBox 是管理「你自己的音樂」的播放器，App 本身不提供任何音樂。請只放入你擁有或有權使用的音樂，例如自行錄製的音檔或自己購買的 CD 轉檔；分享給家人前，也請確認符合該音樂的授權範圍，App 在分享前也會提醒你。

分享專輯需要網路嗎？

用 AirDrop 不需要網路，兩支手機靠近就能傳。也可以用訊息、LINE 或「儲存到檔案」傳送分享檔。

家人會收到什麼？

一個「專輯名稱.musicbox」檔案，裡面有整張專輯的歌曲、曲序、封面和歌詞。對方用 Share MusicBox 打開、按「匯入」就完成；如果已經有同名專輯，會加在裡面並略過重複的歌。

對方沒有安裝 App，可以分享給他嗎？

可以。長按歌曲選「分享音樂檔」，對方會收到一般的 mp3，用任何播放器都能聽。

支援哪些音樂格式？

mp3、m4a、aac、wav、aiff、flac、caf。也支援 .lrc／.txt 歌詞檔，放在同一個資料夾、檔名相同就會自動配對。

Wi-Fi 傳歌安全嗎？

只有在手機上打開「Wi-Fi 傳歌」畫面時才會接收檔案，關掉就停止。網址裡有一組每次都不同的存取碼，同一個 Wi-Fi 的其他人沒有存取碼就無法上傳；而且只接受音樂與歌詞檔。

我的音樂會上傳到雲端嗎？

不會。所有音樂只存在你的手機裡，App 不需要註冊帳號，也不會蒐集任何個人資料。
